# Study Session Website

## Overview
The Study Session Website is a web application designed to enhance study productivity through structured study sessions. It features a timer, chat interface for AI tutoring, and a history log to track study progress.

## Project Structure
```
study-session-website
├── index.html        # Main HTML document for the website
├── css
│   └── styles.css    # Styles for the website
├── js
│   └── app.js        # JavaScript functionality for the website
└── README.md         # Documentation for the project
```

## Features
- **Timer**: A countdown timer to help users focus during study sessions.
- **AI Tutor**: An interactive chat interface that allows users to ask questions and receive concise answers.
- **Session History**: A log that records past study sessions, including details and interactions with the AI tutor.
- **Responsive Design**: The website is designed to be user-friendly and accessible on various devices.

## Setup Instructions
1. **Clone the Repository**: 
   ```
   git clone <repository-url>
   ```
2. **Navigate to the Project Directory**:
   ```
   cd study-session-website
   ```
3. **Open `index.html`**: Open the `index.html` file in a web browser to view the application.

## Usage
- Start a study session by clicking on the "Start Self Study" button.
- Use the timer to manage your study time effectively.
- Interact with the AI tutor by typing questions in the chat box.
- Review your study history to track your progress.
